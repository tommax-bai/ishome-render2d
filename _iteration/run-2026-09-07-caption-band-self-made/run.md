# 叠字白边改成自己造——真跑一轮（2026-09-07）

**裁决**（用户，2026-09-07）：*"把「留白」从「求模型」改成「自己做」。生成侧不再要求留白带"*

## 为什么

情绪图（获客线第一张「你家的样子」）的版面此前是这么来的：imagegen `cream-journal` 模板的
`composition` 里用一句英文向模型讨留白（`RESERVE BLANK PAPER FOR TEXT THAT WILL BE ADDED
LATER: the top 24% and the bottom 28%…`），render2d `style_caption` 叠字前量一遍，
量不到足够的连续空白就整张失败、由 genpipe 重生成一张底图再叠，上限 `max_caption_retries`。

**模型给多少是它的事**。2026-09-07 服务器两跑（Temporal 事件时间线）：

| 跑 | 经过 | 结局 |
|---|---|---|
| 16:00 | 生图 138s → 判不过 → 重生 117s → 判不过 → 重生 151s → 判不过 | 超限，整跑 failed，**业主一张图没收到** |
| 17:04 | 生图 138s → 判不过 → 重生 117s → 判不过 → 重生 151s → 第三张才过 | 成功，总耗时 7 分 26 秒，**其中 7 分钟（94%）耗在这个循环上** |

当日判定数据：顶部实际只有 190px 连续空白，标题块需要 353px。imagegen `494cf6c`
（「情绪图模板留出叠字版面（顶 24%/底 28%）」）已经是加过码的结果——加码也没用。

## 改了什么

- **imagegen**：`templates/cream-journal.json` 的 `composition` 去掉 `RESERVE BLANK PAPER…`
  整段，`negatives` 去掉「不许在预留空白带里画东西」那条。模型现在只管画一张构图完整的画面。
- **render2d**：`style_caption` 由「量版面找空白」改成「自己造版面」——画面**原样**贴进一张
  更高的纸，上下白边高度＝文案按页宽排完的实测高度 ×(1 + 上下各一份 `TEXT_PAD_SHARE`)。
  重试次数恒为 0。

## 量出来的数（改动依据，别当经验值用）

1. **模板去掉留白要求之后画面确实铺满**：92㎡ 那张顶部只剩 29 行整行纯纸，底部 0 行
   （末行还有落影）。改动前后是同一件事的两面——正因为铺满了，才不能再向它要留白。
2. **纸色取四角中位色**：(249,248,243)。四角实测 tl(249,248,243) tr(250,249,244)
   bl(249,248,242) br(249,246,239)——bl 那一角压着阳台，**中位色照样是纸色**，均值不行。
3. **两侧纸色不同**：顶边中位 (249,248,242)、底边 (247,244,236)，差 7 级，是画的落影。
   所以白边底色按**那一侧**取，不是整张一个色。
4. **纯色白边接缝可见**：放大三倍看，接缝那一线由「有颗粒」突变成「死平」
   （对照图 `05-对照-纯色白边顶接缝-放大三倍.png`）。
5. **纸纹镜像铺出去 4 倍段高之后淡尽 → 接缝与重复都看不出**（`03-` / `04-`）。
   段高 29 行、铺 116px。先试过「整条白边都铺纸纹」：29 行的段铺 300px 会铺出
   周期 58px 的竖向条纹（肉眼可见），所以要淡出。
