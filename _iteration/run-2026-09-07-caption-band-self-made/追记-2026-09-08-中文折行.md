# 追记：叠字的中文折行（2026-09-08）

同一层（`style_caption`）的下一件。上一轮把**版面**改成自己造（见同目录 `run.md`），
这一轮修的是**字在版面里怎么折**。`run.md` 正文不改，这一轮的数记在这儿。

## 为什么

上一轮的真跑样张 `~/.ishome/samples-2026-09-07-叠字白边自己造/08-成品-138㎡.png`
底部三块小贴士是这么折的：

```
次卧三扇窗，晾晒和通风        主卧一扇窗，配好窗帘更        阳台细长但通透，种点绿
        都敞亮                      静谧                        植刚刚好
```

`绿植` 被断成 `绿` / `植`。折行是 `_wrap` 按字数硬切（`text[at:at+per_line]`），
**没有任何中文排版规则**：不看标点在哪儿、不管末行剩几个字。

这是业主收到的第一件产品（获客线免费闭环第一张「你家的样子」）的第一印象。

## 改了什么

`src/render2d_worker/style_caption.py` 折行由「按字数硬切」改成**先按句读断，断不开才按字断**：

1. `_clauses`：按 `，。、；：？！…` 把一段话切成短句，标点留在它所属那句的尾巴上。
   **中文没有词间空格，句读是唯一不用分词就能确定的语义边界**——断在这儿一定不在词中间。
2. `_wrap`：把短句当不可拆的整块贪心装行；一个短句本身就宽过一栏才落到 `_by_char`。
3. `_by_char`（按字断那一路）上加两条禁则与一条孤字规则，断点一律**往回退**
   （本行少一个字），不往前进（进会把这一行撑宽过栏，而横向放不下是要整张不出的）：
   - 行首禁则 `_NO_LINE_START`：句读与收尾的括号引号不许领头一行；
   - 行尾禁则 `_NO_LINE_END`：起头的括号引号不许留在行尾；
   - 孤字 `_unorphan`：末行 ≤ `_ORPHAN_TAIL_CHARS` 个字就把最后两行匀一匀。
4. `_ink_center` + 画字锚点由 `ma` 改 `la`：按**墨心**居中，不按字宽居中（见下面第 4 条数）。

**没动**：白边高度的算法、纸纹接缝那套、画面（逐像素校验过，见下面第 5 条）、字号。

## 量出来的数（改动依据，别当经验值用）

1. **真图上一栏放 11 个字**——算出来的：成图宽 1888 → 小贴士字号 `int(1888×0.023)=43`，
   一栏 `1888//3=629`，可用 `int(629×0.82)=515`，`515//43=11`。
   三条贴士 14/13/15 字，都超一行，所以都要折。

2. **按句读断出来比按字硬切匀**（11 字一行）：

   | 小贴士 | 硬切 | 按句读断 |
   |---|---|---|
   | 次卧三扇窗，晾晒和通风都敞亮 | 11 + 3 | 6 + 8 |
   | 主卧一扇窗，配好窗帘更静谧 | 11 + 2 | 6 + 7 |
   | 阳台细长但通透，种点绿植刚刚好 | 11 + 4（`绿`/`植` 断在词里） | 8 + 7 |

   两行都是完整短句，行数没变（还是 2），**所以底部白边高度 192px 一点没动**——
   这一轮不碰白边算法，是真的没碰到。

3. **旧折行在样本上的违例数**（9 句真/拟真文案 × 4~16 字一行，共 117 组）：
   标点领头 **19 处**、开括号留行尾 **1 处**、孤字末行 **27 处**。改完 **0 处**。
   这三个数就是新增那三条门禁的射程——门禁能挂得住，不是空跑。

4. **全角标点的墨只占格子左下角三分之一**，右边三分之二是空的。按字宽居中，
   带逗号收尾的那一行会整体**偏左 16px**（字号 43，合 0.37 个字宽；同一条贴士的
   第二行不带标点，实测偏 0.5px——即"不带标点的行本来是准的"）。同一条小贴士两行
   差 16px，肉眼看得出来。改成按墨迹左右缘的中点居中之后，六行实测偏 −0.5 ~ 0.0px。
   **这个偏差是这一轮的折行改动带出来的**：从前没有哪一行以标点收尾。

5. **画面仍然一个像素不动**：新成品的画面段与输入 `07-画面-138㎡.png` 逐字节相同
   （`tobytes()` 相等），成图仍 1888×2704、顶 336px / 底 192px——与 `08-成品` 同尺寸。

6. **`_ORPHAN_TAIL_CHARS = 2` 不是量出来的**，也不是一条裁决，是这条排版规则本身的定义：
   孤字的说法就是"末行只剩一两个字"，一两个字＝ ≤2。写成常量是为了让判据露在外面，
   不是为了让它看起来有依据——区别于 `BLANK_ROW_TOLERANCE` 那种真量过的阈值。

## 还剩什么：「不在词内断」只做到了一半

**做到的**：断点落在句读上时，词一定完整——这一路纯确定性，不用分词。
真文案的三条小贴士都走这一路。

**没做到的**：一个不带句读的短句本身就宽过一栏时，`_by_char` 仍按字切，**仍可能断在词里**。
判词界要分词，中文分词要引第三方词典依赖（jieba 一类）——**这个仓今天只依赖 Pillow**，
没有先例，且分词本身也只是概率判断（"绿植"是不是一个词由词典说了算，词典没有的照样断错），
把一条纯确定性的排版规则换成一个带词典的猜测，方向不对。**所以停在这儿，没引依赖。**

**也没有拿调字号来兜**：要让最长那条（15 字）一行放下，字号得从 43 压到 34（−21%），
而"字号压到多少还看得清"这个下限**手上没有数据**——没有量过的可读性下限，就不拍这个数。
（`_TEXT_WIDTH_SHARE`/`0.82` 那条栏宽同理：加宽到 0.95 也只有 597px，还是放不下 645px。）

触发条件写死：**哪天真出现"一个不带句读的短句宽过一栏、且断在了词里"的真跑样本**，
拿那张样本再来拍要不要引分词。在那之前不预置。
